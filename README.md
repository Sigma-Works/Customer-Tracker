<h1>Project Overview: </h1>

This project is primarily about tracking a customer's details (such as location, geography, and name). This is done over the span of two classes, one called counter,
which helps determine the customer's ID, and one called customer, which helps establish details relating to the customer's name and geography/location.

There are numerous methods in both classes that help manipulate information and data. The customer class has methods that can help you print out a list of all customers in 
the database, remove customers from said database, and find a specific customer within the database.

The counter class has methods that can help you increment the counter, return the current counter number, and set the counter to a new number. 

The main method is present in the customer class and I've made some objects of the customer class over there. I then went ahead and manipulated these objects with the aforementioned
methods to prove that the code functions as intended.
